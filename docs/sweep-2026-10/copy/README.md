# Teks dari Dika

Folder ini sengaja kosong. Isinya hanya teks yang ditulis Dika sendiri untuk dibaca pengunjung situs; tidak ada
yang menulis atas nama Dika (PRD §1.5, `docs/DECISIONS.md` "reconstruct, never invent").

Yang ditunggu:

- `capital-in-motion-premise.md` (D7). Kalau file ini muncul, teksnya dipasang sebagai satu blok prosa di
  `src/pages/FinanceInMotion.tsx`, satu warna dan satu ukuran, dalam PR susulan fase D. Sampai itu, blok premise
  tidak ada di halaman.

Setiap teks sementara yang dipakai situs ditandai `OWNER-REPLACEABLE` di kodenya dan didaftar di laporan fase di
bawah "Text awaiting the owner"; menaruh pengganti di folder ini adalah cara Dika menggantinya.
