# GATE LEDGER

The primary artefact for the gated-completion mandate. One row per gate.

**States**

- `PASSED` — observed on running software, with the measurement recorded below.
- `CODED-NOT-VERIFIED` — the code exists; the gate was not run. Honest and acceptable; a
  session may end here. Pick it up cleanly next time.
- `BLOCKED` — with the specific reason and what would unblock it.

**A gate is never passed by** `tsc --noEmit`, a green build, passing unit tests, code that
looks correct, or reasoning that it should work. All five were true of `getEssayLink` while
it returned a route that does not exist.

## Notes

### `tsc --noEmit` was checking ZERO files (found 2026-08-01, fixed)

Worth stating loudly, because every "typecheck passes" in this ledger before this
entry was vacuous. The root `tsconfig.json` is solution-style — `"files": []` with only
`references` — so plain `tsc --noEmit` compiles nothing and exits 0. Proven with
`--listFiles`: **0** project files under the old command, **249** under
`tsc -p tsconfig.app.json`.

It surfaced because a JSX syntax error I introduced in `Breadcrumb.tsx` (a `{/* comment */}`
placed as a sibling of the root element inside `return (`) took the entire homepage down with
a 500 — while `npm run typecheck` reported clean. Reintroducing the error confirmed it:
`tsc --noEmit` exit code **0** with the file broken.

`typecheck` is now `tsc -b --force`, which actually builds the referenced projects. Running it
for the first time surfaced two real errors that had been hiding:
`LivePreviewPanel` reached for `.label`/`.url` on `PresentationReference`, which is
`string | {label, url?}` (legacy rows stored bare strings), and `WriterEditor` passed a `Json`
where `EssayPresentation` was expected. Both fixed; a shared `normaliseReference` helper now
handles the string form.

**This is the gate philosophy proving itself.** A green typecheck was one of the five things
the mandate says can never pass a gate, and here it was not merely insufficient — it was
measuring nothing at all.

**Section 0 housekeeping.** `@tiptap/html` confirmed absent from both `package.json` and
`package-lock.json` (0 occurrences in each) — the earlier ambiguity is closed.
